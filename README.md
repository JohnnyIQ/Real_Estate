# 🏡 Real Estate Portal System

## 📌 Overview
The Real Estate Portal System is a web-based application built using **PHP and MySQL**. It allows users to browse, search, and manage property listings. The system supports multiple user roles such as agents, buyers, and renters.

---

## 🚀 Features

### 👤 User Features
- User registration and login (secure with password hashing)
- Browse available properties
- Search properties by city and price
- View detailed property information
- Save and remove favorite properties
- Submit inquiries about properties

### 🏢 Agent Features
- Add new property listings
- Edit existing properties
- Delete properties

### ⚙️ System Features
- Property image upload and display
- Favorites system (toggle save/remove)
- Inquiry system with database storage
- Role-based access control
- SQL View for property listings
- Trigger to update property status after transactions

---

## 🛠 Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** MySQL
- **Server:** XAMPP / Apache
- **Tools:** phpMyAdmin
